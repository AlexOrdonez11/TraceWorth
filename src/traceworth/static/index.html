A SMALL INTEGRATION. A USEFUL START.

Your application.
One shared library.

Add workflow boundaries and record usage from provider responses. Export local events and explore them in the dashboard.

Automatic provider capture is planned. Today, usage is recorded explicitly.

app.pyPYTHON
from traceworth import TraceWorth, JsonlExporter

trace = TraceWorth(
    "my-application",
    JsonlExporter("events.jsonl"),
)

@trace.workflow("answer_request")
def answer_request():
    with trace.span("model_call"):
        # Example only: use actual response usage.
        trace.record_usage(
            "provider", "model",
            {"input_tokens": 100},
        )

# At application shutdown:
trace.close()
Connect the file: traceworth serve --events events.jsonl
